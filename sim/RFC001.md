# RFC 001 revision-5 model

The first executable revision-5 implementation is `intendment/rfc001.py`.
It is separate from the normative stage-1a `intendment/model.py` and the older
`exp/credited-model` branch.

```bash
# From the repository root; standard library only:
python -m unittest discover -s sim/tests -p 'test_rfc001.py' -v
```

See [implementation decisions and boundaries](../docs/rfc-001-implementation.md)
for the ledger, host/resolver assumptions, fee-change handling, appeal defaults,
reservation expiry semantics, mandate commitments, test mapping, and port plan.

This is **not Solidity or a deployment candidate**. All money is simulated.
